# EMLToDocument

Converts standard .eml email files to documents.

## Overview

The `EMLToDocument` component converts email files in the standard `.eml` format (RFC 822 / MIME) into documents. This is the format you get when you save or export emails from Gmail, Thunderbird, Apple Mail, and most other email clients. For Microsoft Outlook `.msg` files, use [`MSGToDocument`](msgtodocument.mdx).

The component extracts the email metadata (sender, recipients, CC, BCC, subject) and the body content, using the same layout as `MSGToDocument`. When an email has both a plain text and an HTML body, the plain text body is used. When it has only an HTML body, the HTML is kept as it is.

Any file attachments are extracted as `ByteStream` objects. An attached email is returned as a `.eml` `ByteStream`, so you can convert it again with `EMLToDocument`.

`EMLToDocument` uses only the Python standard library, so you don't need to install any extra packages.

## Usage

### On its own

```python
from haystack.components.converters import EMLToDocument
from datetime import datetime

converter = EMLToDocument()
results = converter.run(
    sources=["sample.eml"],
    meta={"date_added": datetime.now().isoformat()},
)
documents = results["documents"]
attachments = results["attachments"]

print(documents[0].content)
```

### In a pipeline

The following setup enables extraction and indexing of `.eml` email files within a Haystack pipeline:

```python
from haystack import Pipeline
from haystack.document_stores.in_memory import InMemoryDocumentStore
from haystack.components.routers import FileTypeRouter
from haystack.components.converters import EMLToDocument
from haystack.components.writers import DocumentWriter

router = FileTypeRouter(mime_types=["message/rfc822"])
document_store = InMemoryDocumentStore()

pipeline = Pipeline()
pipeline.add_component("router", router)
pipeline.add_component("converter", EMLToDocument())
pipeline.add_component("writer", DocumentWriter(document_store=document_store))

pipeline.connect("router.message/rfc822", "converter.sources")
pipeline.connect("converter.documents", "writer.documents")

file_names = ["email1.eml", "email2.eml"]
pipeline.run({"router": {"sources": file_names}})
```
